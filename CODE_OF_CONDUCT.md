# Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community. Participate professionally, assume good intent, and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discrimination, threats, sexualized attention, publishing private information, and deliberate disruption. Maintainers may remove content or restrict participation when necessary to keep the project safe.

Report conduct concerns privately to `jerrysabor@gmail.com`.
