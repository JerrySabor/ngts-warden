# Code of Conduct

This project welcomes respectful, professional, and harassment-free participation. Assume good intent and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discrimination, threats, sexualized attention, publishing private information, and deliberate disruption. The maintainer may remove content or restrict participation when necessary to protect contributors and the project.

Report conduct concerns privately to `jerrysabor@gmail.com`.
